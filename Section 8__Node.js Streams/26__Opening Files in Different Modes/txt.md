| Mode     | Meaning                                                                                                   |
| -------- | --------------------------------------------------------------------------------------------------------- |
| **`r`**  | Opens a file for reading. File must exist.                                                                |
| **`r+`** | Opens a file for both reading and writing. File must exist.                                               |
| **`w`**  | Opens a file for writing. Creates the file if it doesn't exist; truncates it if it does.                  |
| **`w+`** | Opens a file for both reading and writing. Creates the file if it doesn't exist; truncates it if it does. |
| **`a`**  | Opens a file for appending. Creates the file if it doesn't exist.                                         |
| **`a+`** | Opens a file for reading and appending. Creates the file if it doesn't exist.                             |
