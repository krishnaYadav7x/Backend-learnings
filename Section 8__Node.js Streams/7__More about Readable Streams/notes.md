| Event        | Meaning                                           |
| ------------ | ------------------------------------------------- |
| `'open'`     | The file has been opened successfully.            |
| `'data'`     | A chunk of data is available in flowing mode.     |
| `'readable'` | Data is available to be read.                     |
| `'end'`      | All readable data has been consumed.              |
| `'close'`    | The stream or its underlying resource has closed. |
| `'error'`    | An error occurred.                                |
