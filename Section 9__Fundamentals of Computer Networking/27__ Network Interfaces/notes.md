# Network Interfaces – Ways to Connect to the Internet

* **1. Network Interface**

  * A network interface allows a device to connect and communicate with a network.
  * It can be wired or wireless.
  * Examples: Ethernet, Wi-Fi, Bluetooth and USB.

* **2. Different Ways to Connect to the Internet**

  * **Ethernet (Wired Connection)**

    * Uses an Ethernet cable to connect a laptop/computer to a router.
    * Provides a stable and generally faster connection.
    * Router's DHCP server usually assigns an IP address.

  * **Wi-Fi (Wireless Connection)**

    * Connects devices to the internet wirelessly through a router.
    * No physical cable is required.
    * Router's DHCP server assigns an IP address.

  * **Bluetooth Tethering**

    * Connects a laptop to a mobile phone using Bluetooth.
    * Mobile phone shares its mobile internet with the laptop.
    * Phone's networking system usually assigns an IP address through DHCP.

  * **USB Tethering**

    * Connects a laptop to a mobile phone using a USB cable.
    * Mobile phone shares its mobile internet with the laptop.
    * Phone's networking system usually assigns an IP address through DHCP.

  * **Mobile Data (3G/4G/5G)**

    * Phone connects to the internet through nearby cellular towers.
    * Mobile network/ISP assigns IP configuration to the phone.
    * No Wi-Fi router is required.

* **3. Who Assigns IP Addresses?**

  * Ethernet/Wi-Fi: Router's DHCP server usually assigns a private IP address.
  * Bluetooth/USB tethering: Mobile phone's DHCP service usually assigns an IP address to the connected laptop.
  * Mobile Data: Mobile network/ISP assigns IP configuration to the phone.
  * **Important:** Cables themselves do not assign IP addresses. IP addresses are assigned by network services such as DHCP.

* **4. Different Ways to Access the Internet on a Mobile Phone**

  * Mobile Data (3G/4G/5G).
  * Wi-Fi connection.
  * Bluetooth tethering.
  * USB tethering.
  * Ethernet connection (using a compatible adapter).

* **5. Quick Revision**

  * Wired Connections: Ethernet and USB.
  * Wireless Connections: Wi-Fi, Bluetooth and Mobile Data.
  * A network interface can be hardware-based or software-based.
