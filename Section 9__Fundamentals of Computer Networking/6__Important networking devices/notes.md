* **1. Host**

  * A device that sends or receives data over a network.
  * Examples: Laptop, mobile phone, computer, server.
  * **Use:** Communicates and exchanges data with other devices.

* **2. Repeater**

  * Receives and regenerates a weakened signal.
  * **Use:** Extends the distance a signal can travel.

* **3. Hub**

  * Connects multiple devices in a network.
  * **Use:** Sends incoming data to all other connected ports.
  * **Limitation:** Does not identify the intended destination device.

* **4. Switch**

  * Connects multiple devices within a local network (LAN).
  * **Use:** Forwards data toward the intended device using MAC addresses.
  * **Advantage:** Reduces unnecessary traffic compared with a hub.

* **5. Bridge**

  * Connects two LAN segments.
  * **Use:** Filters and forwards data between segments using MAC addresses.
  * **Note:** A switch performs a similar function but typically has more ports.

* **6. Router**

  * Connects different IP networks.
  * **Use:** Forwards packets toward their destination using IP addresses and routing information.
  * **Example:** Connects your home network to your ISP's network.

* **7. Modem**

  * Modulates and demodulates signals to communicate over a particular transmission medium.
  * **Use:** Helps connect your home to your ISP's network using technologies such as cable or DSL.
  * **Note:** Some devices combine a modem and router into one box.

## Differences Between Networking Devices

| Device   | Main purpose                                | How it works                           |
| -------- | ------------------------------------------- | -------------------------------------- |
| Host     | Sends and receives data                     | Participates in network communication  |
| Repeater | Extends signal reach                        | Regenerates a weakened signal          |
| Hub      | Connects devices                            | Sends incoming data to all other ports |
| Switch   | Connects devices within a LAN               | Forwards frames using MAC addresses    |
| Bridge   | Connects LAN segments                       | Filters frames using MAC addresses     |
| Router   | Connects different networks                 | Forwards packets using IP addresses    |
| Modem    | Connects through an ISP's access technology | Modulates and demodulates signals      |

## Important Points to Remember

* **Host:** Participates in communication.
* **Repeater:** Regenerates signals.
* **Hub:** Sends data to all other ports.
* **Switch:** Forwards data toward the correct device within a LAN.
* **Bridge:** Connects and filters traffic between LAN segments.
* **Router:** Forwards packets between networks.
* **Modem:** Enables communication over an ISP's access technology.
* **Wi-Fi:** A wireless networking technology, not a synonym for a router.
* **Internet:** A global network of interconnected networks.
