| Method         | Syntax / Arguments                    | Purpose                           |
| -------------- | ------------------------------------- | --------------------------------- |
| `readFile()`   | `readFile(path, options)`             | Read a file                       |
| `writeFile()`  | `writeFile(path, data, options)`      | Create / write / overwrite a file |
| `appendFile()` | `appendFile(path, data, options)`     | Add content to a file             |
| `copyFile()`   | `copyFile(source, destination, mode)` | Copy a file                       |
| `cp()`         | `cp(source, destination, options)`    | Copy files/directories            |
| `rename()`     | `rename(oldPath, newPath)`            | Rename or move                    |
| `unlink()`     | `unlink(path)`                        | Delete a file                     |
| `rm()`         | `rm(path, options)`                   | Remove file/directory             |
| `mkdir()`      | `mkdir(path, options)`                | Create directory                  |
| `stat()`       | `stat(path, options)`                 | Get file/directory information    |
| `watch()`      | `watch(path, options, callback)`      | Watch for changes                 |
