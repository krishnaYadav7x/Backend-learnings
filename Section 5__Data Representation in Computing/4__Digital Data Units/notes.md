# 📦 SI vs IEC — Digital Storage Units

## 🔹 Basic Idea

There are two standards for measuring digital storage:

- **SI** → Decimal system → Base 10
- **IEC** → Binary system → Base 2

> 💡 Remember: **8 bits = 1 byte**

---

## 📊 SI vs IEC

SI (Decimal)  IEC (Binary) 

| KB = 1,000 bytes  KiB = 1,024 bytes 
| MB = 1,000 KB  MiB = 1,024 KiB 
| GB = 1,000 MB  GiB = 1,024 MiB 
| TB = 1,000 GB  TiB = 1,024 GiB 

---

## 🔢 SI — Base 10

SI uses powers of **10**:

1 KB = 10³ bytes
1 MB = 10⁶ bytes
1 GB = 10⁹ bytes
